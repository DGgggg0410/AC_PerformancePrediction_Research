## 项目需求

将三个深度学习模型项目（LSTM、Transformer、Mamba-LSTM）中的虚拟数据替换为GitHub开源真实数据集，并调整所有相关代码以适配新的5维特征输入格式。

## 核心数据变更

- **数据来源**：GitHub开源数据集 VaclavNezerka/AsphaltFatigueANN
- **文件名**：asphalt_20_deg.xlsx
- **样本数**：206个（经Z-score过滤后）
- **输入特征**：5维（binder_content, air_voids, strain_level, temperature, frequency）
- **目标变量**：fatigue_life（N_f，千次循环）
- **SEQ_LEN**：从10改为1（无时序数据）

## 特征映射关系

| 原代码特征 | 新数据集特征 | 说明 |
| --- | --- | --- |
| oil_stone_ratio | binder_content | 沥青含量 |
| void_ratio | air_voids | 空隙率 |
| stress | strain_level | 应变水平 |
| temperature | temperature | 温度 |
| - | frequency | 加载频率（新增） |
| mineral_powder | - | 删除 |
| asphalt_type | - | 删除 |
| aggregate_grade | - | 删除 |
| stiffness_* (10列) | - | 删除（无时序） |


## 技术方案

### 数据下载与转换

1. 使用Python的requests库从GitHub下载Excel文件
2. 使用pandas读取Excel并转换为CSV格式
3. 将同一份数据复制到三个项目的data目录

### 特征工程调整

- INPUT_DIM: 8 → 5
- SEQ_LEN: 10 → 1
- 删除时序劲度模量相关代码
- 保留归一化、数据划分逻辑

### 模型结构调整

- LSTM: 全连接层展平从 hidden_dim*10 → hidden_dim
- Transformer: 位置编码seq_len从10改为1
- Mamba-LSTM: 同LSTM调整
